## Aralarındaki Bağ

```
        ZARIEL  ◄── sözleşmedeki imza (Molly Thorne'un köşkünde bulundu)
          ▲
          │ hizmet / rekabet
          │
         BEL  ──► "3. Lejyon" recruitment ağı ──► Wheatrest portal dungeon
                                                          ▲
                                                   parti buradan girdi
                                                          │
      MARCUS HALE ──► partiyi gönderen ──► max'ın hocası
```

Bel, partiyle **yüz yüze karşılaştı** ve imzalanmamış bir sözleşme bıraktı:
*"Her şey bitmeden önce tekrar karşılaşacağız."*
→ **Wheatrest dungeon**
