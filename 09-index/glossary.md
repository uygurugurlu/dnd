# Sözlük

Bu evrende kullanılan terimler. **Oyun terimleri İngilizce tutulur** — bu tablo
karşılıklarını değil, **ne anlama geldiklerini** açıklar.

## Kozmoloji

| Terim | Ne demek |
|---|---|
| **Great Wheel** | Evrenin düzlem yapısı; iç içe halkalar |
| [Material Plane](../01-cosmology/material-plane.md) | Ager'in bulunduğu somut düzlem |
| **Outer Planes** | Ahlak ve inancın 16 düzlemi; tanrıların diyarı |
| **Inner Planes** | Elemental düzlemler; maddenin ham hâli |
| **Transitive Planes** | Astral ve Ethereal — geçiş düzlemleri |
| **Echo Planes** | Feywild ve Shadowfell — Material'in yankıları |
| **Layer** | Bir düzlemin katmanı (Nine Hells'in 9, Abyss'in sonsuz katmanı var) |
| **Realm** | Bir tanrının kendi düzleminde tuttuğu diyar |
| **Demiplane** | Küçük, yapay ya da doğal cep evren |
| **Color pool** | Astral'dan bir Outer Plane'e açılan renkli geçit |
| **Gate-town** | Outlands'te bir düzleme açılan kapının etrafındaki şehir |
| **Fey crossing / Shadow crossing** | Feywild/Shadowfell'e geçiş noktası |
| **Wildspace** | Bir yıldız sistemi içindeki boşluk |
| **Astral Sea** | Yıldız sistemleri arasındaki boşluk |
