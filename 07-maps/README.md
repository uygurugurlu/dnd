## Sahne Görselleri

Battle map ve sahne görselleri, ait oldukları **yerin/kampanyanın yanında**
`attachments/` klasörlerinde tutuluyor (Notion'daki gibi bağlamlarında kalsınlar diye):

| Konum | Ne var |
|---|---|
| `03-ager/.../ravonia/attachments/` | Amber Square, Molly Thorne köşkü, Drunkard, sewers, underground |
| `03-ager/.../villages/nethryn/attachments/` | Nethryn köyü, kilise, harabeler |
| `03-ager/.../villages/wheatrest-attachments/` | Wheatrest dungeon odaları |
| `06-campaigns/chains-of-the-burning-compact/attachments/` | Turnuva, Zhentarim, Kırık Rüyalar, combat 1, Aysif |
| `06-campaigns/oneshot-clathropos/attachments/` | Ruins, meydan dövüşü, Quill 4 |

## Adlandırma

```
world-<slug>.jpg       Dünya haritası
continent-<slug>.png   Kıta
nation-<slug>.png      Ülke
region-<slug>.png      Bölge
city-<slug>.jpg        Şehir
battle-<slug>.png      Savaş haritası (1 kare = 5 ft, 70px/kare)
planar-<slug>.png      Düzlem
```

Varyantlar: `-player` (sırlar çıkarılmış) ve `-dm`.
