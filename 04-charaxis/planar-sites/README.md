# Altı İniş — *the Landings*

> Ager'de altı kapı var. Charaxis'te **altı iniş** var. Aynı altı yarık,
> öbür ucundan bakınca.

**Yukarı:** [Charaxis](../README.md) ·
**Ager tarafı:** [Charaxis Kapıları — Portal Ağı](../../03-ager/planar-sites/portal-network.md) ·
**Hat:** [Bölgeler](../regions/README.md)

## 1. Cevap: hepsi Meridyen Yolu'na çıkmaz

Ager'in portal dosyasındaki açık soru buydu ve cevabı şu: **beşi yola çıkar,
biri çıkmaz.**

Ve kapıların dağılımında bir düzen var — Mürai savaşından sonra **siyasi** hâle
gelen bir düzen:

| | Ravonia'nın üç kapısı | Karsovia'nın üç kapısı |
|---|---|---|
| **Nereye iniyor** | Hattın **Kül yarısı** | Hattın **Don yarısı** |
| **Ne var orada** | Adamantine, mithral, moondust, altın | Gümüş, chronoshard, buz, ceset |
| **Yıllık değeri** | Yüksek | Düşük |
| **Kim kazandı savaşı** | Kaybetti | **Kazandı** |

> **Hattaki en sert ironi:** Karsovia Ager'de savaşı kazandı ve Charaxis'te
> gezegenin **fakir yarısını** miras aldı. Ravonia yenildi, ordusu dağıtıldı,
> devleti zayıfladı — ama zengin yarım hâlâ onun kapılarından iniyor.
>
> Karsovia bunu 1495'te fark etti. [Vidrek Solyan](../../05-characters/npcs/minor/vidrek-solyan.md)
> bu farkın adamıdır.

## 2. Altı iniş

### Toz İnişi — *R-1*

| | |
|---|---|
| **Ager ucu** | [Urkhal Ovaları](../../03-ager/continents/ravonia/regions/urkhal-plains/README.md) — ork toprağı |
| **Charaxis ucu** | [Ashkar Reach](../regions/ashkar-reach.md), Kül-71 |
| **Kim tutuyor** | [Gharuk Kumpanyası](../factions.md#gharuk-kumpanyası) — Kapı masası |
| **Ne geçiyor** | **Moondust.** Hattın en değerli tek kalemi |
| **Yol** | İniş şehrin içinde; yola çıkmaya gerek yok |
| **Durum 1495** | Aktif, kalabalık, **kararsız** |

Hattın kalbi. Gharuk'un bütün serveti bu tek kapıdan geçiyor ve bunu herkes
biliyor. Kapı kapanırsa ork ekonomisi çöker — ve
[Ataman Ghorag'ın](../../03-ager/continents/ravonia/regions/urkhal-plains/README.md#ataman-ghorag)
ulus projesi onunla birlikte.

### Yanlış İniş — *R-2*

| | |
|---|---|
| **Ager ucu** | [Wheatrest](../../03-ager/continents/ravonia/villages/wheatrest.md) doğusu — kırsal |
| **Charaxis ucu** | **Yol dışı.** Kül-77'nin 3 mil yukarısı, cam düzlükte |
| **Kim tutuyor** | Kimse |
| **Ne geçiyor** | Resmen hiçbir şey. Gerçekte: kaçak toz, kaçak adam, kaçak ceset |
| **Yol** | Yok. İnenler 3 mili **denge yüküyle** yürür; yük 1 kol dayanır, yürüyüş 2 saat |
| **Durum 1495** | **Stabilite %62** (1492 kaydı). Bugün daha kötü |

Tek "yanlış" iniş. Elfler 1385'te sabitlerken hedefi tutturamadı — ya da
tutturdu ve yol o zamandan beri kaydı. İnen kişi kendini yolun *üstünde*
değil, **yukarısında** bulur: sıcak, cam, ve iki saatlik yürüyüş.

> **[HOOK]** Ashkar Reach'in kayıtsız nüfusunun büyük kısmı bu kapıdan geldi.
> Yanlış İniş, hattaki **tek kayıtsız giriş noktası** ve bu yüzden herkesin
> ihtiyacı olan şey.
> Cam düzlükte, iki saatlik yürüyüş hattı boyunca, ceset var. Sayılmıyorlar.

### Beşik — *R-3*

| | |
|---|---|
| **Ager ucu** | [Stone Raven](../../03-ager/continents/ravonia/sites/stone-raven.md) — Ravonia şehrinin limanı |
| **Charaxis ucu** | [Brakk-Dur Omurga](../regions/brakk-dur.md), peron, Kül-28 |
| **Kim tutuyor** | [Örs Beratı](../factions.md#örs-beratı--the-anvil-charter) |
| **Ne geçiyor** | **Cevher.** Adamantine, mithral, demir — hattın ağır yükü |
| **Yol** | İniş peronun üstünde; vinçler doğrudan kapıya yükler |
| **Durum 1495** | Aktif; hattın en düzenli işleyen kapısı |

Adı, kapının çevresine kurulmuş vinç kafesinden geliyor: yük kapıdan bir
beşik gibi sarkıtılarak geçirilir. Ravonia'nın devlet siparişleri buradan iner
ve ordu dağıtılmış olsa da **adamantine siparişi iptal edilmedi.**

### Sıfır Terası — *K-3*

| | |
|---|---|
| **Ager ucu** | [Karsovia şehri](../../03-ager/continents/karsovia/cities/karsovia.md) — başkentin içi |
| **Charaxis ucu** | [Vael'Serith](../regions/vael-serith.md), Sıfır Taşı'nın 200 adım doğusu |
| **Kim tutuyor** | [Nöbet](../factions.md#nöbet--the-watch) |
| **Ne geçiyor** | Memur, elçi, izin, Aether Quartz. **Yük değil** |
| **Yol** | Terastan taşa taş döşeli 200 adım. Hattın en temiz yolu |
| **Durum 1495** | Aktif; en sıkı denetlenen kapı |

Kazanan kıtanın başkenti, gezegenin **tam ortasına**, elflerin ayağının dibine
iniyor. Karsovyalı memurlar bunu bir ayrıcalık sayıyor. Nöbet bunu bir **sorun**
sayıyor ve hiçbir şey söylemiyor.

### Gümüş Basamak — *K-2*

| | |
|---|---|
| **Ager ucu** | [Northwatch](../../03-ager/continents/karsovia/sites/northwatch.md) kuzeydoğusu — yol kavşağı |
| **Charaxis ucu** | [Widowsilver](../mines/widowsilver.md) kampı, Don-38 |
| **Kim tutuyor** | [Soğuk İmtiyaz](../factions.md#soğuk-i̇mtiyaz--the-cold-concession) |
| **Ne geçiyor** | Gümüş yukarı; **işgücü aşağı** |
| **Yol** | Kamptan kapıya 400 adım, buz oyuğunda; iki tarafta muhafız |
| **Durum 1495** | Aktif. Tek yönlü işleyen bir kapı gibi *hissettiriliyor* |

Ravonyalı borçluların çoğu buradan gelmedi — **buradan gidemiyor.** Kapının
Charaxis tarafında bir masa var ve masada borç defteri duruyor. Borcu olan
geçemez. Bu bir kural değil, bir **uygulama** — ve ikisinin farkı hattaki
avukatların tek geliri.

### Soğuk Basamak — *K-1*

| | |
|---|---|
| **Ager ucu** | [Surfwale](../../03-ager/continents/karsovia/sites/surfwale.md) doğusu — Lover's Cut |
| **Charaxis ucu** | [Stillreach](../regions/stillreach.md), Don-64 |
| **Kim tutuyor** | Soğuk İmtiyaz + 140 Karsovyalı asker |
| **Ne geçiyor** | Chronoshard, ceset, mahkûm, memur |
| **Yol** | Şehrin içinde |
| **Durum 1495** | Aktif; hattın **askerî** kapısı |

Karsovia'nın Charaxis'e açılan asıl ağzı. İki denetim üst üste: kalenin ve
şirketin. Bir cesedi Ager'e geçirmenin resmî ücreti **12 gp**'dir ve bu ücret
ölünün borcuna eklenir.

## 3. Geçmenin üç engeli — Charaxis tarafı

[Ager tarafındaki üç engelin](../../03-ager/planar-sites/portal-network.md#6-masada-kullanım)
buradaki karşılığı:

| Engel | Charaxis'te nasıl işler |
|---|---|
| **Şifre** | Aynı: *"Vael'Toruun u thalas—shaen, khar."* Burada bunu **herkes** bilir; şifre bir engel değil |
| **Yetki** | Şirket kâğıdı. Gharuk pulu, Örs Beratı imzası, İmtiyaz defteri. Sahtesi Ashkar'da 200 gp |
| **Borç** | ⚠️ **Charaxis'e özgü dördüncü engel.** Borçlu geçemez. Hattaki insanların çoğunu tutan şey budur — muhafız değil, **defter** |
| **Kararsızlık** | 1494'ten beri her geçiş kumar → [d6 tablosu](../../06-campaigns/new-campaign/05-world-seeds.md) |

> **[DM ONLY]** Kapıları [1385'te elfler sabitledi](../../03-ager/planar-sites/portal-network.md#1-nasıl-oluştular);
> sabitleme [Sıfır Taşı'na](../regions/vael-serith.md#sıfır-taşı) bağlı. Vuruş
> kaydıkça sabitleme de kayıyor. Yani portalların kararsızlaşması bir kuyruklu
> yıldız etkisi değil, **bir saat problemi** — ve saati tamir etmek Ager'de
> değil, burada mümkün.
>
> Bunu bilen üç taraf var: [Isthaen](../../05-characters/npcs/minor/isthaen-of-the-zero-stone.md)
> (defteri var), Nöbet (biliyor, saklıyor), ve
> [Saatçiler](../factions.md#saatçiler--the-hourwrights) (hesapladı, satmayı düşünüyor).
