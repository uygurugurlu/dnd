# Kozmoloji — The Great Wheel

Ager evreninin fiziği **Great Wheel** kozmolojisidir. Bu bölüm doğrudan Forgotten Realms
canon'undan gelir ve değiştirilmez. Ager'in kendisi, bu çarkın merkezindeki
[Material Plane](material-plane.md)'de yer alan bir dünyadır.

**Ana dosya:** [great-wheel.md](great-wheel.md) — çarkın tamamı, katmanlar, nasıl bağlanıyor.
