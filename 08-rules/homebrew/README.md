# Homebrew

Bu evrene özgü mekanik içerik. **Lore dosyaları burada değil** — burada sadece
kurallar ve statblock'lar.

| Klasör | Ne | Lore karşılığı |
|---|---|---|
| [species/](species/) | Özgün oynanabilir türler | `02-lore/peoples/` |
| [subclasses/](subclasses/) | Özgün subclass'lar | — |
| [spells/](spells/) | Özgün büyüler | `02-lore/magic/` |
| [items/](items/) | Sihirli eşyalar, artifaktlar | ilgili yer/karakter dosyası |
| [monsters/](monsters/) | Statblock'lar | `02-lore/bestiary/` |
| [backgrounds/](backgrounds/) | Ager'e özgü background'lar | — |

## Kural

Homebrew mekanik **İngilizce** yazılır (masada okunacak metin).
Lore kısmı Türkçe, ilgili lore dosyasında.

## Denge Kontrol Listesi

Yeni homebrew eklerken:
- [ ] Mevcut bir resmî seçenekle karşılaştırıldı mı?
- [ ] Hangi seviyede geliyor, o seviyede uygun mu?
- [ ] Action economy'yi bozuyor mu?
- [ ] Bir sınıfın kimliğini çalıyor mu?
- [ ] Bir masada test edildi mi?
