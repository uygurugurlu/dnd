## Faydalı Tablo Tipleri

- **Encounter tabloları** — bölge başına (`<bolge>-encounters.md`)
- **Söylenti tabloları** — şehir/kasaba başına
- **Han/taverna** — isim, sahibi, özellik, o gece olan şey
- **NPC üretimi** — isim, görünüş, istek, sır
- **Hazine** — bölgeye uygun loot
- **Hava durumu** — mevsim ve bölgeye göre
- **Komplikasyonlar** — bir sahne durgunlaşınca
