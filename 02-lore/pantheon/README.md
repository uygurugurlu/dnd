# Pantheon

Ager'in tanrıları **Forgotten Realms pantheon'udur**. Tanrılar aynıdır; kültleri,
tapınakları ve Ager'deki siyasi ağırlıkları homebrew'dur.

| **racial/** | Cüce, elf, drow, halfling, gnome, orc pantheon'ları |
