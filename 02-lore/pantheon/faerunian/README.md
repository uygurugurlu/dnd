# Faerûnian Pantheon

Ager'in ana pantheon'u. Forgotten Realms'in tanrıları aynen kullanılır.
2025 *Heroes of Faerûn* kitabı 42 tanrıyı "büyük tanrılar" olarak listeler.

**Detaylı dosyası olanlar** aşağıda linkli; diğerleri tabloda özet hâlde.
Bir tanrı kampanyada önem kazandığında dosyaya terfi eder.
