# Archdevils — Lords of the Nine

**Nine Hells**'in dokuz katmanının
hükümdarları. Tanrı değildirler (Asmodeus istisna) ama tanrı gücüne yakındırlar
ve ölümlülerden ibadet ve **ruh** toplarlar.

## Ortak Kurallar

- **Sözleşme yaparlar.** Yalan söyleyemezler ama gerçeği eksik söylerler.
- **Hiyerarşiye bağlıdırlar.** Asmodeus'a itaat ederler — açıkça.
- **Birbirlerine komplo kurarlar.** Asmodeus buna izin verir; düzenli entrika,
  düzensiz isyandan iyidir.
- **Ruh toplarlar.** Ana para birimi budur; Blood War'ın yakıtı.
- **Blood War'da savaşırlar.** Ana cephe Avernus, yani Zariel'in katmanı.
