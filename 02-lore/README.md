# 02 — Evrensel Lore

Belirli bir yere bağlı olmayan her şey. Bu bölüm ağırlıklı olarak
**Forgotten Realms canon**'undan gelir; Ager'e özgü uyarlamalar her dosyanın
"Ager'de" bölümünde işaretlenir.

| Bölüm | Ne var |
|---|---|
| **pantheon/** | Tanrılar, archdevil'ler, demon lord'lar, ilahi mekanikler |
| **magic/** | Weave, Shadow Weave, dead/wild magic, büyü gelenekleri |
| **history/** | Zaman çizelgesi, çağlar, takvim, Sundering'ler |
| **peoples/** | Türler ve kültürleri |
| **factions/** | Kıtalar arası örgütler |
| **languages/** | Diller ve yazı sistemleri |
| **bestiary/** | Evrene özgü yaratıklar |
| **organizations-minor/** | Yerel loncalar, küçük düzenler |
