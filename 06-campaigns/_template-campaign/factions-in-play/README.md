# Faksiyonlar — Bu Kampanyada

Faksiyonların **tam dosyaları** `02-lore/factions/` altında.
Burada sadece bu kampanyadaki durumları ve parti ile ilişkileri.

## İtibar (Renown)

| Faksiyon | İtibar | Rütbe | Son değişim |

| | 0 | — | |

**İtibar kaybetme:** hedeflerine karşı çalışma, üyelerine zarar verme

| İtibar | Rütbe | Ayrıcalık |

| 1 | Rütbe 1 | Temel destek, bilgi |
