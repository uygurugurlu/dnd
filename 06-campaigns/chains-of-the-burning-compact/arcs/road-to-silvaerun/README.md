## Üç rota

```
                         ┌── A · KARA ──── Thornhold ── Gorestead ── Mournwood ── Tharn'Kel ──┐
                         │      (~16 gün, savaş)                                              │
  WHEATREST ─────────────┤                                                                    ├──► EIRA'THALAS ──► CAÉLORA
   (soygundan sonra)     │                                                                    │    (~4 gün, doğa)   (Yaprak Kapısı)
                         ├── B · KISA ATLAMA ── R-2 ══ Charaxis (Kül-77 → Ashkar) ══ R-1 ── Urkhal ──┘
                         │      (~1 gün Charaxis + ~4 gün kara)
                         │
                         └── C · ELF YOLU ── R-2 ══ Hat boyunca ~80 mil ══ Vael'Serith ══ Nöbet'in çemberi ══► CAÉLORA
                                (~5–6 gün + Nöbet)                                                              (Kök Salonu)
```

| | **A · Kara + Orman** | **B · Kısa Atlama** | **C · Elf Yolu** |
|---|---|---|---|
| **Süre** | ~20 gün | ~9 gün | ~6 gün (+ Nöbet ile pazarlık) |
| **Asıl tehlike** | Savaş, kapalı geçit, sonra **doğa** | Charaxis sıcağı, **R-1'deki yetki**, sonra **doğa** | Sıcak, ham büyü, Nöbet bürokrasisi, **siyaset** |
| **Orman** | Tam geçiş (doğudan, Tharn'Kel) | Tam geçiş (güneyden) | **Yok** — ormanın üstünden atlar |
| **Para** | Az | 40 gp bilet/kişi + sahte yetki (200 gp) ya da Murag'la anlaşma | Denge yükü, Isthaen'in bedeli |
| **Nereye varır** | Yaprak Kapısı — **davetsiz** | Yaprak Kapısı — **davetsiz** | Caélora'nın **içine**, konseyin ortasına |
| **Davet** | Orman "geçirdiyse" (Dikkat ≤ 1) sayılır | Aynı | Isthaen'in kefaleti = davet — ama **108 yıllık** |
| **Zariel'in rünü** | Ormana girerken **Dikkat +1** | Aynı | Charaxis'te de çalışır — Zariel kısa süreliğine "başka dünyaya" gittiklerini hisseder |
