# Oneshot — Clathropos

> **Clotho + Lachesis + Atropos** → *Clathropos.* Kaderin Kız Kardeşleri.

**Yukarı:** **Kampanyalar**

## Tema

Yunan mitolojisindeki **Moirai** — tüm ölümlülerin ve tanrıların kaderlerini,
yaşam sürelerini ve ölümlerini belirleyen üç tanrıça. Yaşam ipliğini eğirir,
ölçer ve keserler. Bu oneshot onların etrafında kuruldu:
**Sisters of Faith**.
